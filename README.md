# 💬 Customer Support Chatbot

An **AI-powered chatbot** designed to automate responses to customer queries.  
This chatbot uses **Natural Language Processing (NLP)** to understand user inputs and provide relevant answers — improving support efficiency and customer satisfaction.

---

## 🧠 Objective
To create an intelligent chatbot that can handle common customer queries like order tracking, refunds, and delivery details automatically.

---

## ⚙️ Approach
The chatbot is built using:
- **Python (Flask)** – backend server for chatbot logic and API.
- **NLP Techniques** – for intent detection and text matching.
- **HTML, CSS, JavaScript** – for a simple and clean frontend interface.

---

## 💡 Features
✅ Responds to customer greetings and support queries  
✅ Handles requests like *order tracking*, *refunds*, and *delivery time*  
✅ Provides fallback responses for unknown questions  
✅ Interactive web-based chat interface  
✅ Easy to extend by adding more intents or connecting to a real API  

---

## 🚀 How to Run the Project

### 1️⃣ Clone this repository
```bash
git clone https://github.com/<your-username>/customer-support-chatbot.git
cd customer-support-chatbot
```
### 2️⃣ Create a virtual environment
```bash
python -m venv venv
```
### 3️⃣ Activate it
Windows:

```bash
venv\Scripts\activate
```
Mac/Linux:
```bash
source venv/bin/activate
```
### 4️⃣ Install dependencies
```bash
pip install flask nltk
```
### 5️⃣ Run the app
```bash
python app.py
```
Then open your browser and visit 👉 http://127.0.0.1:5000/
